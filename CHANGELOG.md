# Changelog

Versions track the media kit, not the status of the projects described in it. A changed kit does not itself establish a new portrait authorisation or a completed product launch.

## 1.0.0 · 2026-10-12

- Initial public release of Paul Fleury's official media kit.
- One authorised portrait in 16 PNG, JPEG, and WebP exports, capped at 512 pixels with embedded metadata removed.
- Copy-ready biographies, life and work, a curated project index, and a short personal statement.
- PF marks, application-style icons, README header, project map, and social card.
- Limited editorial media permission for identity materials, with a separate MIT license for original functional build code.
- Reproducible exports, an asset manifest, automated checks, and a downloadable ZIP with SHA-256 verification.
